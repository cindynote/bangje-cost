# 방제 원가계산기

수목진료 표준품셈(산림청, 2025.6.) 「2-1. 병해충 방제제 살포」 기준 원가계산 웹앱입니다.

- 수목현황(표본목 흉고·수고) → 약제 → 진단비 → 원가계산서 순으로 입력하면 바로 계산됩니다.
- 결과 탭의 **엑셀로 내보내기**는 입력값을 원가계산서 엑셀 양식에 채워, 수식이 살아 있는 파일로 내려받습니다.
- 서버 없이 브라우저에서만 동작하며, 입력값은 이 브라우저에만 저장됩니다.

## 파일
- `index.html` — 웹앱 (엑셀 양식이 페이지 안에 포함되어 있음)
- `원가계산서_양식.xlsx` — 같은 엑셀 양식 원본

## 기준
- 노임: 2026년 수목진료 인건비 기준단가, 건설업 시중노임(2026.1.1)
- 제비율: 조달청 간접공사비 적용기준(2026.4.13.), 조경·공사규모 10억원 미만
- 진단비: 품셈 1-1 진단 [별첨1] (일반관리비 6%, 이윤 10%)
